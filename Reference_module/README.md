### External Model Setup: RhoFold+
This project relies on RhoFold+ for RNA 3D structure generation.

Please download the RhoFold+ repository and extract it into the Reference_module directory.[RhoFold+](https://github.com/ml4bio/RhoFold)

```bash
unzip RhoFold-main.zip -d ./PRISM-main/Reference_module/
```
